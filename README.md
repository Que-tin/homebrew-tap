# Homebrew tap

Apps by [Que-tin](https://github.com/Que-tin), for [Homebrew](https://brew.sh).

```sh
brew install --cask que-tin/tap/gloam
```

- **[Gloam](https://github.com/Que-tin/gloam)**: a blue light filter for your Mac that warms and
  dims the screen from sunset to bedtime.

The casks follow each app's latest release by themselves (`.github/workflows/update.yml`).
